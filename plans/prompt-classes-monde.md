# Prompt : concevoir toutes les classes du pays vivant ( ecrit le 23/09 a la demande de Younes )

Younes : « Ecris-moi un prompt : tu demandes de creer des classes pour le projet ultra complet, une vraie eco, une
vraie medecine, tout pousser a fond dans chaque domaine de la vie, concessionnaire vehicule etc, militaire, les armes,
les tactiques... La conversation ne doit faire que ca. »

Le prompt complet est dans le message de la session du 23/09 ; il tient en sept parties : le projet tel qu il existe,
les classes existantes a etendre, vingt domaines a couvrir ( economie, banques, travail, industrie, agriculture,
energie, vehicules et concessionnaires, logistique, immobilier, medecine, demographie, education, justice, Etat,
militaire avec armes, optiques, logistique, renseignement et tactiques comme objets, medias, culture, climat, services
publics ), les huit regles non negociables du moteur ( conservation exacte, echelle, etat distinct de la decision avec
interface d agent, determinisme, incarnation Arma, mesurabilite, style, realisme ), les lecons deja payees, le format
de chaque livraison, et le deroule ( carte des domaines d abord, puis un domaine complet par reponse ).
